# 🧠 AI/ML Quiz App

## 📖 Overview

The **AI/ML Quiz App** is an Android application designed to help students, beginners, and AI enthusiasts improve their knowledge of **Artificial Intelligence** and **Machine Learning** through interactive quizzes. The application provides multiple-choice questions categorized into **Easy, Medium, and Hard** difficulty levels with an intuitive user interface for an engaging learning experience.

The app is suitable for academic practice, interview preparation, certification exams, classroom activities, and self-assessment.

---

# ✨ Features

* 🎯 **Three Difficulty Levels**

  * Easy
  * Medium
  * Hard

* 📝 **80+ AI & Machine Learning Questions**

  * Covers AI fundamentals
  * Machine Learning concepts
  * Deep Learning
  * Neural Networks
  * NLP
  * Computer Vision
  * Transformers
  * Evaluation Metrics

* 🔀 **Randomized Answer Options**

  * Answer choices are shuffled to reduce memorization and improve learning.

* 📊 **Score Tracking**

  * Displays the final score after quiz completion.
  * Helps users evaluate their understanding.

* 📱 **Modern Mobile UI**

  * Clean and minimal interface.
  * Easy navigation between screens.

* ⚡ **Interactive Quiz Experience**

  * One question displayed at a time.
  * Instant response selection.

* 🎨 **Simple and User-Friendly Design**

  * Soft color palette
  * Rounded buttons
  * Easy readability

* 📚 **Educational Learning Tool**

  * Suitable for students preparing for AI/ML interviews and university examinations.

# 🎥 App Workflow

1. Launch the application.
2. Tap **Start Quiz**.
3. Choose a difficulty level.
4. Answer multiple-choice AI/ML questions.
5. Navigate through the quiz.
6. View your final score.
7. Retry or choose another difficulty level.
